# 12. 用語定義

<!-- ドキュメント内で使っている言葉の意味を統一します。
     チーム開発では「認識齟齬」（言葉の理解違い）が多くのトラブルの原因になります。 -->

| 用語 | 意味 |
|---|---|
| ボード | アプリの画面全体。リストが並んでいる場所 |
| リスト | カードをまとめる縦の列。「未着手」「進行中」など |
| カード | 1件のタスク。タイトルとメモを持つ |
| ドラッグ&ドロップ | マウスで要素をつかんで別の場所に移動する操作 |
| LocalStorage | ブラウザ内にデータを保存する仕組み。サーバー不要 |
| モーダル | 画面上に重ねて表示するポップアップウィンドウ |
| バニラJS | フレームワークを使わない素のJavaScript |

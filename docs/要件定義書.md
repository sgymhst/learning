# スケジュール管理アプリ 要件定義書

作成日: 2026-11-24

---

## 1. プロジェクト概要

Trello風のカードベースUIを持つ、個人向けスケジュール管理Webアプリを開発する。
仕事・プライベートのタスクを一元管理できるシンプルなツールを目指す。

本プロジェクトはアプリ開発の学習を目的とし、実務と同様の開発フロー（要件定義→設計→実装→テスト）を体験することを重視する。

---

## 2. 利用者・利用シーン

| 項目 | 内容 |
| --- | --- |
| 利用者 | 個人（1名） |
| 利用シーン | 仕事のタスク管理 / プライベートの予定管理 |
| 利用環境 | PC Webブラウザ（デスクトップ・ラップトップ） |

---

## 3. 機能要件

| # | 機能 | 説明 |
| --- | --- | --- |
| 1 | カード作成 | タスクをカード形式で新規作成できる |
| 2 | カード編集 | カードのタイトル・メモを後から編集できる |
| 3 | カード削除 | 不要なカードを削除できる |
| 4 | カードにメモ記入 | カードに説明文を記入できる |
| 5 | リスト管理 | リスト（コラム）を自由に作成・編集・削除できる |
| 6 | ドラッグ&ドロップ | カードをリスト間でドラッグ&ドロップで移動できる |
| 7 | データ保存 | ブラウザのローカルストレージに自動保存・読み込みする |

---

## 4. 非機能要件

| 項目 | 内容 |
| --- | --- |
| データ保存 | ブラウザのローカルストレージを使用（PC・ブラウザ毎のデータとなる） |
| デザイン | シンプルで機能重視（デザイン性は一時保留） |
| 対応環境 | モダンブラウザ（Chrome / Firefox / Edge 想定） |
| 言語 | 日本語 UI |
| 技術スタック | HTML / CSS / JavaScript（初学者でも理解しやすい構成） |

---

## 5. スコープ外（今回作らない機能）

- 期日（締め切り日）の設定
- 複数ユーザー対応（チーム共有）
- ログイン / 認証機能
- カードへのファイル添付
- スマートフォン対応（レスポンシブデザイン）
- 通知・リマインダー機能
- クラウドシンク（サーバーサイドでのデータ保存）

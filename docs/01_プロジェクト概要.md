# 1. プロジェクト概要

## 1-1. 背景・目的

現状、仕事とプライベートのタスクが頭の中や紙のメモに散在しており、抜け漏れが発生しやすい状態にある。  
タスクを一覧で可視化できるWebアプリを作ることで、自己管理の効率化を図る。

また本プロジェクトは、アプリ開発の実務フロー（要件定義 → 設計 → 実装 → テスト）を体験することも目的とする。

## 1-2. アプリ概要

Trelloを参考にした、カードベースUIのスケジュール管理Webアプリを開発する。  
「リスト（カテゴリ列）」の中に「カード（タスク）」を配置し、ドラッグ&ドロップで状態を管理できるシンプルなツールを目指す。

## 1-3. 開発期間・フェーズ

| フェーズ | 内容 |
|---|---|
| 要件定義 | 何を作るかを決める（現在） |
| 設計 | 画面・データ構造を設計する |
| 実装 | コードを書く |
| テスト | 動作確認・修正 |

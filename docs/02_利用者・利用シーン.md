# 2. 利用者・利用シーン

## 2-1. 利用者プロファイル

<!-- 実務では「ペルソナ」と呼びます。誰のために作るかを明確にします -->

| 項目 | 内容 |
|---|---|
| 利用者 | 個人（1名） |
| PCスキル | 一般的なWebアプリが使える程度 |
| 利用目的 | 仕事・プライベートのタスクを一元管理したい |
| 利用頻度 | 毎日、朝と夕方に確認・更新 |
| 利用環境 | PCのWebブラウザ（デスクトップ・ラップトップ） |

## 2-2. 利用シーンのイメージ

- 朝：今日やることをカードに追加する
- 仕事中：作業が終わったカードを「完了」リストに移す
- 夕方：残タスクを確認して翌日の準備をする

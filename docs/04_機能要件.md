# 4. 機能要件

<!-- 優先度の意味:
     Must（必須）: これがなければアプリとして成立しない
     Should（推奨）: できれば欲しい
     Could（任意）: 余裕があれば -->

| # | 機能名 | 説明 | 優先度 | 対応US |
|---|---|---|---|---|
| F-1 | カード作成 | タスクをカード形式で新規作成できる | Must | US-1 |
| F-2 | カード編集 | カードのタイトル・メモを後から編集できる | Must | US-3 |
| F-3 | カード削除 | 不要なカードを削除できる | Must | US-4 |
| F-4 | カードへのメモ記入 | カードに説明文・詳細を記入できる | Must | US-2 |
| F-5 | リスト作成 | リスト（カラム）を新規作成できる | Must | US-5 |
| F-6 | リスト編集 | リスト名を変更できる | Must | US-5 |
| F-7 | リスト削除 | 不要なリストを削除できる | Must | US-5 |
| F-8 | ドラッグ&ドロップ（リスト間） | カードをリスト間でドラッグ&ドロップで移動できる | Must | US-6 |
| F-11 | ドラッグ&ドロップ（リスト内） | 同じリスト内でカードをドラッグ&ドロップで並び替えられる | Must | US-8 |
| F-9 | データ自動保存 | 操作のたびにローカルストレージへ自動保存する | Must | US-7 |
| F-10 | データ読み込み | ブラウザを開いたとき、前回のデータを復元する | Must | US-7 |

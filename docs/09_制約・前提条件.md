## 技術スタック

| レイヤー | 技術 | 選定理由 |
|---|---|---|
| フロントエンド | React | コンポーネント指向で学習価値が高い。現場での利用率も高く実践的 |
| スタイリング | CSS（素のCSS または CSS Modules） | 外部UIライブラリは使わず、CSSの基礎を身につける |
| D&Dライブラリ | SortableJS | 軽量・Reactとの相性が良い。リスト間・リスト内の両方に対応 |
| ビルドツール | Vite | 軽量・高速。React開発の標準的な選択肢 |
| バックエンド | Java / Spring Boot | 学習教材に準拠。REST APIをSpring MVCで実装する |
| データ永続化 | Spring Data JPA（Hibernate） | Spring Boot標準のORMでDBアクセスを実装 |
| データベース | PostgreSQL | 本格的なRDB。Docker Composeで環境を統一する |
| API通信 | REST（JSON） | フロントエンドとバックエンドをREST APIで接続 |

## その他の制約

| 種別 | 内容 |
|---|---|
| 開発制約 | 1人開発のため、複雑な機能は優先度を下げる |
| 環境制約 | PCブラウザのみ対応（スマートフォン対応は対象外） |

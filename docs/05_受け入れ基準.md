# 5. 受け入れ基準

<!-- 受け入れ基準 = 「この条件を満たしたら完成とみなす」というテスト基準。
     曖昧な「できる」だと、どこまで作れば完成なのかが分からなくなります。
     実務ではQAエンジニアがこれをもとにテストを設計します。 -->

| 機能 | 受け入れ基準（これを満たしたら完成） |
|---|---|
| F-1 カード作成 | ・「＋」ボタン等でカード作成フォームが開く<br>・タイトルを入力して保存すると、対象リストにカードが追加される<br>・タイトルが空のまま保存しようとすると、エラーまたは保存不可になる |
| F-2 カード編集 | ・カードをクリックすると編集モードになる<br>・タイトル・メモを変更して保存すると、カードの表示に反映される |
| F-3 カード削除 | ・削除ボタン押下で確認ダイアログが出る<br>・「OK」でカードが消える。「キャンセル」で元に戻る |
| F-8 D&D移動（リスト間） | ・カードをドラッグして別リストにドロップすると、そのリストに移動する<br>・移動後もデータが正しく保存されている |
| F-11 D&D並び替え（リスト内） | ・同じリスト内でカードをドラッグすると、ドロップした位置に並び替えられる<br>・リストの先頭・末尾・中間すべての位置に挿入できる<br>・並び替え後もデータが正しく保存されている |
| F-9/F-10 保存・復元 | ・カード追加後にブラウザをリロードしても、カードが消えていない<br>・別タブで開くと同じデータが表示される |

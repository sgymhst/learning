# 3. ユーザーストーリー

<!-- ユーザーストーリーとは「誰が・何のために・何をしたいか」を短文で書いたもの。
     機能要件を考える前に書くと、「本当に必要な機能」が明確になります。
     形式: 「〇〇として、△△のために、□□したい」 -->

| # | ユーザーストーリー | 対応する機能 |
|---|---|---|
| US-1 | ユーザーとして、新しいタスクが発生したとき、すぐカードを作成したい | カード作成 |
| US-2 | ユーザーとして、タスクの詳細を忘れないように、カードにメモを残したい | カードへのメモ記入 |
| US-3 | ユーザーとして、タスクの内容が変わったとき、カードを修正したい | カード編集 |
| US-4 | ユーザーとして、完了したタスクを削除して、リストをすっきりさせたい | カード削除 |
| US-5 | ユーザーとして、タスクの状態（未着手・進行中・完了など）を管理するために、リストを自由に作りたい | リスト管理 |
| US-6 | ユーザーとして、タスクの状態が変わったとき、カードをドラッグで別リストに移したい | ドラッグ&ドロップ |
| US-7 | ユーザーとして、ブラウザを閉じてもデータが消えないようにしたい | データ保存 |
